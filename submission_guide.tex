\section*{1. Gemini API Key Configuration}
An active Google Gemini API key is already configured for evaluation:
\begin{itemize}
    \item \textbf{Pre-configured in ZIP Package:} The included \texttt{.env} file already contains an active \texttt{GEMINI\_API\_KEY}. The app loads it automatically on startup with zero manual configuration.
    \item \textbf{Alternative Key (Optional):} To evaluate with a different key, edit \texttt{.env} or run \texttt{export GEMINI\_API\_KEY="your\_key"} in terminal.
\end{itemize}

\section*{2. Environment Setup \& Installation}
Requires Python 3.10+ and internet access (for Wikipedia retrieval \& Gemini API).
\begin{enumerate}
    \item \textbf{Extract ZIP and enter directory:}
\begin{verbatim}
unzip marsh-case-study.zip && cd marsh-case-study
\end{verbatim}
    \item \textbf{Create and activate virtual environment:}
\begin{verbatim}
python3 -m venv venv
source venv/bin/activate          # On Windows: venv\Scripts\activate
\end{verbatim}
    \item \textbf{Install required packages:}
\begin{verbatim}
pip install -r requirements.txt
\end{verbatim}
\end{enumerate}

\section*{3. Launching the Application}
\begin{enumerate}
    \item \textbf{Start the web studio:}
\begin{verbatim}
python3 server.py
\end{verbatim}
    \item \textbf{Open browser:} Navigate to \href{http://localhost:8000}{\textbf{\texttt{http://localhost:8000}}}
    \item \textit{(Alternative Streamlit UI):} Can also be run via \texttt{streamlit run app.py}
\end{enumerate}

\section*{4. Generating a Pitch \& Running the Audit}
\begin{enumerate}
    \item \textbf{Select Target Company:} Enter a company name (e.g., \textit{Infosys}, \textit{Zomato}, \textit{TCS}) or click a preset.
    \item \textbf{Select Policies:} 4 IRDAI policy brochures are pre-selected. Optionally drag-and-drop a new policy PDF to index dynamically.
    \item \textbf{Execute Pipeline:} Click \textbf{"Generate Grounded Pitch \& Run Audit"}. The 3-step pipeline profiles the client via Wikipedia, synthesizes slides, and runs a two-step factual audit.
\end{enumerate}

\section*{5. Reviewing \& Exporting Deliverables}
\begin{itemize}
    \item \textbf{Slide Deck Preview:} Browse the interactive presentation carousel with commercial insurer brandings.
    \item \textbf{Compliance \& Audit Tab:} View audit status (PASS/FAIL), confidence score, and click any clause tag to open the \textbf{Clause Inspector Modal} to view the exact original filing text.
    \item \textbf{Download Presentation (.pptx):} Click \textbf{"Download Pitch Deck (.pptx)"} to render and download the executive slide deck on demand.
    \item \textbf{Download Audit Report (.pdf):} Click \textbf{"Download Audit Report (.pdf)"} to render and download the official compliance traceability report.
\end{itemize}
