\section*{1. Submission Directory Navigation}
The submission ZIP contains documentation PDFs alongside the project codebase folder:
\begin{verbatim}
unzip marsh-submission.zip
cd marsh-submission/project       # Enter the inner project codebase directory
\end{verbatim}

\section*{2. Gemini API Key Configuration}
An active Google Gemini API key is required for LLM reasoning and entity synthesis:
\begin{itemize}
    \item \textbf{Pre-configured in ZIP Package:} The \texttt{project/} directory includes a pre-configured \texttt{.env} file containing an active API key. The application loads it automatically on startup.
    \item \textbf{Command to Set Key (Just in case):} If the \texttt{.env} file is missing or you wish to provide your own key, run either command in the \texttt{project/} directory:
\begin{verbatim}
echo 'GEMINI_API_KEY="your_api_key_here"' > .env
# OR export directly in your shell:
export GEMINI_API_KEY="your_api_key_here"
\end{verbatim}
\end{itemize}

\section*{3. Environment Setup \& Installation}
Requires Python 3.10+ and internet access (for Wikipedia retrieval \& Gemini API calls).
\begin{enumerate}
    \item \textbf{Create and activate a virtual environment:}
\begin{verbatim}
python3 -m venv venv
source venv/bin/activate          # On Windows: venv\Scripts\activate
\end{verbatim}
    \item \textbf{Install required dependencies:}
\begin{verbatim}
pip install -r requirements.txt
\end{verbatim}
\end{enumerate}

\section*{4. Launching the Web Studio}
\begin{enumerate}
    \item \textbf{Start the application server:}
\begin{verbatim}
python3 server.py
\end{verbatim}
    \item \textbf{Open your browser:} Navigate to \href{http://localhost:8000}{\textbf{\texttt{http://localhost:8000}}}
    \item \textit{(Alternative Streamlit UI):} Can also be launched via \texttt{streamlit run app.py}
\end{enumerate}

\section*{5. Quick Evaluation Workflow}
\begin{enumerate}
    \item \textbf{Select Target Entity:} Type any company (e.g., \textit{Infosys}, \textit{Zomato}, \textit{TCS}) or click a preset button.
    \item \textbf{Policy Baseline:} The 4 IRDAI approved brochures are pre-indexed. You may also drag-and-drop any new policy PDF into the upload zone to chunk and index dynamically.
    \item \textbf{Run Pipeline:} Click \textbf{"Generate Grounded Pitch \& Run Audit"}. The 3-step pipeline profiles the client via Wikipedia, synthesizes slides, and executes a two-step factual audit.
    \item \textbf{Audit \& Clause Inspector:} In the \textbf{Compliance \& Audit} tab, view the audit score (PASS/FAIL) and click any clause tag to open the \textbf{Clause Inspector Modal} with original source text.
    \item \textbf{Download Deliverables:} Click \textbf{"Download Pitch Deck (.pptx)"} and \textbf{"Download Audit Report (.pdf)"} to render and download both files on demand.
\end{enumerate}
